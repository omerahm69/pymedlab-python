# pymedlab-python
PyMedLab Python — Python for Medical Physics and Medical Imaging
This repository contains the Python learning materials accompanying PyMedLab.
The course is designed to help learners develop Python programming skills through practical examples related to medical physics, medical imaging, DICOM, image processing, and artificial intelligence.
