
# Module 2 — Python Fundamentals

This module introduces the fundamental concepts needed to write Python programs. Students will learn how to store information, make decisions, repeat operations, organize data, create reusable code, and finally introduce object-oriented programming.

Throughout the module, examples are connected to medical physics, medical imaging, DICOM, laboratory measurements, and healthcare technology.
## Lessons

1. Variables and Data Types
2. Operators and Expressions
3. Functions
4. Input and Output
5. Conditional Statements
6. Loops and Repetition
